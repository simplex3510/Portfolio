# 루트 기획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 제목 | Portfolio_M |
| 장르 | TPS 로그라이트 액션-어드벤처 |
| 개발 형태 | 솔로 인디 개발 |
| 엔진 | Unity 6.6 (새 Input System Package 사용) |
| 아트 스타일 | 3D 로우 폴리 모델링 |

---

## 2. 장르 재정의 이력

- 최초 컨셉: "로그라이크-소울라이크 RPG"
- 현재 확정 컨셉: **"로그라이트 액션-어드벤처"**로 재정의됨
- 재정의 배경: 소울라이크 특유의 고난이도·정밀 전투 중심보다, 탐험과 성장·수집의 재미에 무게중심을 두는 방향으로 조정

---

## 3. 벤치마킹 대상

| 참고작 | 참고 요소 |
|---|---|
| Moonlighter | 낮/밤(활동/던전) 이원 구조, 수집·거래 루프 |
| 레전드 오브 곡괭이 | 모노톤·실루엣 중심 그래픽 및 UI 톤 |
| 소울류 | 자유 이동/닷지 조작감 |
| 사이퍼즈 | 피격 모션 존재, 공격-스킬 조작법 |

---

## 4. 핵심 게임플레이 루프 (개요)

- 실시간 이동 + 실시간 전투가 동시에 진행되며, **전투 중 일시정지 없음**
- 이동/닷지는 소울류 및 사이퍼즈의 자유 방향 조작
- 던전은 재입장 시 완전 재생성되며, "런(run)"이라는 별도 프레이밍 없이 진행
- 사망 시 자원 손실 후 허브(베이스)로 귀환
- 허브에서 장비 강화와 스킬 시스템이 별도 축으로 존재

---

## 5. 톤 앤 매너

- 전체적인 톤: 밈/패러디 성격이 강한 가벼운 분위기
- 메인 시나리오: 진지한 톤 유지
- 즉, **일상적 진행은 가볍고 유머러스하되, 메인 스토리 서사는 진지하게 대비되는 이중 톤 구조**
- 톤 전환 연출(BGM 컷, 보스 타이틀 카드, 컬러 그레이딩 등)은 아이디어 후보 단계이며 **현재 개발 우선순위 아님**

---

## 6. 아트 방향 (개요)

- 기본 그래픽: 3D 로우폴리 모델링
- UI 컨셉: 레전드 오브 곡괭이류의 모노톤·실루엣 중심 그래픽을 셀 아트 스타일에 맞게 어레인지

---

## 7. 개발 원칙 (프로젝트 전반)

- **계획 규모 원칙**: 구조/아키텍처 수준은 먼저 확정하되, 수치 밸런스는 구현 직전 또는 프로토타입 검증 후 결정, 개별 스킬의 세부 스펙은 실제 제작 시점에 결정
- **개발 페이스**: 한 번에 과도한 분량의 코드/스크립트를 작성하지 않고 단계적으로 진행
- **확장성 vs 과설계**: 확장성은 고려하되 과설계는 지양, 직관적이고 비축약적인 코드 스타일 지향
- **멀티플레이**: 싱글 플레이 완성 후 검토 예정 (해당 시점 도래 시 먼저 제안하기로 합의됨). 현재는 네트워크 코드를 작성하지 않되, 입력 처리와 판정 로직을 분리하는 등 구조적 여지만 남겨둠
